## Breve Descripción
Un sitio mockup para una plataforma de Turismo Local para una ciudad ficticia de nombre "Destino Cordillera".

## Instrucciones
El sitio se puede ver abriendo el archivo index.html en la carpeta raíz en un navegador cualquiera, pero probar con un servidor de nginx o http de python debería funcionar sin problemas también, ya que el sitio es completamente estático.

## Tecnologías Usadas
- HTML5
- CSS3
- Bootstrap 5.3.8
